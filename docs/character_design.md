# 主人公再デザイン：Vera Thornforge（ヴェラ・ソーンフォージ）

**一言キャッチ：温室を守るためなら、鋼の規則も刈り払う。**

## 背景設定

ヴェラは、植物の規格外成長をかばってクビになった熱核植物学者であり、温室事故の現場で救助と障害物の切断を担ってきた成人女性。廃棄された剪定装置を大剣に、研究用の鉢原子炉を装甲の動力に改造し、生きた苗を処分する園芸ロボットの工場へ踏み込む。機械の融通の利かなさには不敵な笑みで応じ、切り開いた道では必ず小さな芽を拾う。

本案は主人公の外見と演出の設計。既存の The Botanist に対応する人物として扱い、ゲーム内名称や能力、数値の変更は行わない。既存アートディレクションの色・形の意味を継承し、主人公の描画は今回指定のドット絵に置き換える。

## 外見とシルエット

- **髪・顔：** 腰まで届く工場ティールの長い髪。銅の留め具で後頭部を一箇所だけ束ね、毛先は左後方に流れる大きな二房にまとめる。温かい褐色の肌、鋭い眉、落ち着いた目と小さな不敵な笑み。成人らしい顔立ちを保つ。
- **体格・姿勢：** 肩と脚に筋力のある戦士体型。両足を開いて重心を低くし、顔・胸・武器を右へ向ける。胸や腰を誇張するポーズは避け、踏ん張りと武器の重さで強さを見せる。
- **鎧：** インクティールの分割装甲に銅の縁取り。胸甲は胸元が深く開いたV字で自然な谷間を見せるが、胸部は不透明な装甲で確実に覆い、乳首・胸の下側は見せない。腹部を覆う胴鎧、長ズボン、厚い籠手と脛当てを備え、戦闘用の装備としてまとめる。背側の肩に大きな陶器クリームの葉形肩甲、腰には短い左右二枚の装甲垂れ。装甲の継ぎ目にだけ太いミントの蔓を絡ませ、髪や手足を埋めない。
- **武器：** 身長の約3分の2の長さの両手持ち「炉刃剪定剣」。幅広い直線的な剪定刃、先端の小さな枝受けの切り欠き、銅の配管一本、刃の中央を走るライムの炉心溝で識別する。通常時の発光は小さな色面に留め、斬撃時だけアイボリーの芯を点灯する。
- **動力と装備：** 背中の小型鉢原子炉は陶器製の下半分と保護枠付きガラス鐘で構成し、中の芽を一枚だけ見せる。前腕のシアンの二重六角機構が Overshield、反対側の籠手にある太い三本の植物トゲが Pointy、背中の銅排熱口とコーラルの熱波が Overheat、腰のプラム色の廃液カプセルと継ぎ目の一滴が Waste の視覚的な対応。これらは装備意匠であり、待機中に能力発動や常時バリアを描かない。

一目で読む形は「左へ流れる長髪」「片側の葉形肩甲」「右へ突き出す幅広い剣」の三つ。髪と背中の炉、剣と前脚の間に透明な隙間を残す。文字、紋章、ロゴ、他作品由来の衣装や固有シルエットは使わない。

## アニメーション設計

idle と attack はそれぞれ左から右へ4コマを横一列に並べ、等幅セル、全身、右向き、同じ縮尺・足元基準を守る。セル内の足裏は高さ94%付近、上下左右に最低6%の余白を確保し、髪・刃先・軌跡もセル内に収める。カメラや人物全体を上下にずらさず、足元を固定する。

| idle | 動作 | 表示時間の目安 |
| --- | --- | --- |
| 1 | 基準の構え。両手で剣を右斜め上に保持し、両足を接地。 | 200ms |
| 2 | 息を吸って肩が論理1px上がる。毛先は一拍遅れて論理1px左へ、剣先は論理1px上へ。 | 200ms |
| 3 | 呼吸の頂点。肩を保ち、毛先だけさらに論理1px揺れる。握りと足の位置は保つ。 | 200ms |
| 4 | 息を吐いて肩と剣を基準位置へ戻し、毛先も1コマ目へ自然につながる位置に戻す。 | 200ms |

idle は1→2→3→4→1のループ。胸部だけを揺らさず、動きは呼吸と髪・武器の小さな揺れに限定する。

| attack | 動作 | 表示時間の目安 |
| --- | --- | --- |
| 1：構え | idle 1と同じ形。右の敵を見据え、剣を両手で構える。 | 90ms |
| 2：振りかぶり | 両足の接地を保ち、膝を曲げて上体をひねる。剣を頭の上へ引き上げ、髪は左後方へ遅れて流れる。 | 110ms |
| 3：斬撃 | 上体を右へ送り、剣を右下へ斜めに振り抜く。ライムとアイボリーの短い角張った弧を一つだけ描き、背中の排熱口に小さなコーラルの熱波を出す。 | 70ms |
| 4：戻り | 剣と重心を基準の構えへ戻す。軌跡と熱波は消え、毛先だけ少し遅れて収まり、idle 1へ接続する。 | 130ms |

攻撃は1回再生して待機に戻す。斬撃は3コマ目で読むが、ダメージ処理や既存VFXの実装変更は今回の対象外。フレームごとに髪の長さ、装甲の左右、肌色、武器形状を変えない。

## アイコンとバストアップ

hero_icon は顔と葉形肩甲を中心にした胸上の肖像。右向きの顔、銅の髪留め、長髪の二房を残し、顔の判読を優先して小さな装備は省略する。hero_card_bust は頭から腰上までを描き、深いV字胸甲、前腕の二重六角、剣の柄と刃の一部、背中の芽を見せる。どちらも同じ成人女性・装備・配色を保持し、透過余白を最低10%取る。

JSONの指定メタデータはそのまま保持する。横4コマの配置は sheet と prompt で指定し、画像生成・生成スクリプトの変更・ゲームへの組み込みは行わない。
