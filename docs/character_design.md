# 主人公：Vera Emberscale（ヴェラ・エンバースケイル）

**一言キャッチ：竜の血が騒いだら、爪と炎の翼で道を開く。**

旧デザイン（温室の植物学者 Vera Thornforge）は git 履歴を参照。能力・数値・カードは変えず、見た目・名前・説明文だけを差し替えた。

## 方針（IP の扱い）

「半竜の女戦士が竜の力を解放する」という誰でも使える元型から作ったオリジナルキャラ。
公開 OSS なので、既存ゲームのキャラクター名・顔・衣装・固有デザイン、地名・紋章・ロゴ、公式アートの模写は使わない。
配色（深紅の髪＋赤銅の鱗）は雰囲気を寄せる程度にとどめ、シルエットで区別する。

## 竜化の演出（アニメーション）

普段は人の姿。力を使う瞬間だけ、肩甲骨から半透明の炎の翼が出る。

| シート | コマ | 動き |
| --- | --- | --- |
| idle | 1 | 両手の竜爪を胸の前に構えた低い構え。動きはゲーム側の呼吸 Tween（上下3px）だけ。4コマで描かせるとコマごとに描き直されて体が数px跳び、5fps でガクガクに見えたため1枚にした（manifest の `keep_frames: 1`） |
| attack | 4 | 構え → 深くかがんで右手を引き、炎の翼が開き始める → 踏み込んで竜爪で引き裂く（炎の三本爪の軌跡、翼は全開） → 構えに戻り翼は火の粉になって消える |
| hurt | 3 | 右から受けてのけぞる → いちばん深いよろめき → 歯をむいて立て直す |
| block | 3 | 両腕の籠手を交差 → 炎の翼を前に巻いて盾にする → 翼が消えて構えに戻る |

プロンプトは `tools/codex_art/hero_painted_assets.json`（`python tools/codex_art/generate.py --manifest tools/codex_art/hero_painted_assets.json`）。master 以外のアセットには `refs` で正本画像を添付し、デザインは添付画像に、ポーズは文章に従わせる。

## 共通の世界と主人公専用の分け方

主人公は今後増えたり差し替わったりする。本家 StS2 と同じく、敵・世界・汎用の絵はどの主人公でも同じものを使い、主人公ごとに変わるのはそのキャラのカードと専用アイコンだけにする。

| 区分 | 中身 | 画風（manifest） |
| --- | --- | --- |
| 共通の世界 | 敵、「?」イベント、汎用の状態異常、レリック、ポーション、VFX、行動予告、HUD、宝箱、ショップ、無色のカード、無色のコスト玉 | 主人公を匂わせない（竜の鱗・爪・尾・翼・竜炎・人物を描かない）。敵は `enemy_assets.json`、ほかは `assets.json` / `event_assets.json` |
| 主人公専用 | その色のカード、そのカードだけが付ける状態異常（Fever Dream / Boiling Blood / Blood Heat / Fire Feeds Fire）、その色のコスト玉とレリック | 竜の鱗・爪・血・炎。`hero_ui_assets.json`、カードは `realm_assets.json`（緑カードだけ） |

イベントの本文も、主人公の体（爪・竜の血など）に触れず、誰が来ても通じる文にする。

## 祝福のキャラ：幕の開始地点で贈り物をくれる住人

StS の Neow（StS2 では幕ごとに変わる Ancient）にあたる役。共通の世界の住人なので、どの主人公にも同じキャラが出る。各幕の開始地点で、シードで決まる順に3体のうち1体が現れ、幕ごとに違うキャラが来る。データは `scripts/content/BlessingContent.gd`、画面と演出は `scripts/ui/RunStartOptions.gd` と `scripts/ui/BlessingGiver.gd`、絵のプロンプトは `tools/codex_art/event_assets.json`（共通の世界の画風）。

| ID | 名前 | 見た目 | 祝福の傾向 |
| --- | --- | --- | --- |
| blessing_goddess | Mossy Goddess（苔むした女神像） | 苔と蔦に覆われた石の女神像。目と衣の線が青緑に光る | 最大HP・強化・ポーション |
| blessing_merchant | Wandering Trader（旅の商人ゴーレム） | 山のような荷物を背負った小さな青銅のゴーレム | ゴールド・ポーション・レリック |
| blessing_spirit | Antlered Spirit（角の森の精霊） | 青緑の光でできた鹿。角は生きた枝 | カードの除去・変化・獲得 |

選択肢は Neow 風に、代償なしの「小さな祝福」2つと、代償つきの「大きな祝福」1つ。1幕目だけ、開始武器とボスレリック交換も並ぶ。選ぶとキャラが光って一言しゃべり、光の玉が受け取り先の HUD（レリック欄・ポーション欄・デッキ・ゴールド・HP）へ飛んで弾ける。

## カード：竜の爪・尾・翼・炎

緑カードの絵は、主人公の籠手と竜爪・尾・炎の翼・竜炎で描く（顔は描かない）。名前もこれに合わせ、テーマ語を差し替えた：炉心 → 竜炎（Dragonfire）、放射性廃棄物 → 燃えさし（Cinder）、オーバーヒート → 竜血の熱（Blood Heat）、剪定の刃 → 研ぎ澄ました爪、炉心籠手 → 竜炎の籠手。内部 ID（`reactor` タグ、`card_waste` など）は変えていない。
