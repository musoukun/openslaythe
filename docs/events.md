# イベント設計 (「?」マスの非戦闘イベント)

実装: `scripts/content/EventContent.gd` / イベント画像: `tools/codex_art/event_assets.json` (Codex 生成)

## 調査メモ: Slay the Spire 2 のイベント (2026-09)
- イベントは「?」マスでのみ発生。幕専用 + 共有イベントがあり、条件 (所持金・ポーション・遺物) を満たすものから均等に選ばれる。
- 条件を満たさない選択肢は **ロック表示のまま残す** (次回の動機になる)。
- 「安全で小さい報酬」と「危険で大きい報酬」の2択が基本形。数値は幅のある乱数が多い。
- 退出は必ずしも保証されず、「小さい報酬の選択肢」が実質の退出になる設計が多い。
- 相場: 遺物1つ ≒ HP 8〜15 / 最大HP 8〜13 / 呪い1枚 / 100〜200G。HP 6〜8 で 50〜100G。回復は 20HP〜33%、最大HP +5〜10。
- 出典: slaythespire.wiki.gg (StS2 Events / Events List / Ancients), spire-codex.com/events, sts2.wiki/events, thegamer.com StS2 events guide ほか

## 抽象化した「型」と、このゲームのオリジナルイベント

| 型 (意図) | オリジナルイベント | 選択肢 |
|---|---|---|
| 1. HPで永続の力を買う (今の余力 ⇔ 将来の強さ) | **Leaking Sprinkler** 漏れた炉心スプリンクラー | 霧を浴びる: HP-10 → ランダム遺物 / 流れ水を汲む: ポーション1 |

| 3. お金の段階的な使い道 (貯金の価値を問う) | **Seed Vault Vending Machine** 種子保管庫の自販機 | 40G: ポーション2 / 120G: 遺物 / 220G: レア遺物 / 去る |
| 4. もう1回だけ (欲張るほどコスト増) | **Compost Jackpot** 堆肥の山 | 掘る(HP-4, 30G) → もっと掘る(HP-6, 60G) → 底まで(HP-8, 遺物)。いつでもやめられる |

設計ルール
- すべてのイベントに「無難な選択肢」を用意し、詰まない (HPが足りない選択肢はロック)。
- 報酬の大きい選択肢ほど、コストか不確実性が大きい。
- 呪いの代わりに、このキャラのメカニクスに合う **放射性廃棄物 (Waste)** を負のカードとして使う。
