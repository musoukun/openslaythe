# 2人目の主人公：青の少年魔法剣士（設計案）

**一言キャッチ：マナで呪文を連打するか、マナを注いだ固有の蒼刃で斬り伏せるか。**

ユーザーの要望（2026-10-16）：

- 仕組み：「マナ」というポイントを溜めて使う。StS2 で言えばリージェント（2つ目の資源「Stars」と、育つ専用武器 Sovereign Blade）に近い。
- ビルドの2つの軸は「ヘイスト（1ターンにカードを何枚も打つ）」と「マナでキャラ固有の技を強化する」。
- 見た目：カサディンのような雰囲気で、中性的なマッシュルームカットの少年魔法使い。イメージ色は青。

この文書は実装前の設計案。名前と見た目は、デザイン候補（`tools/codex_art/refs/mage_concepts.png`）からユーザーが選んでから確定する。

## 方針（IP の扱い）

公開 OSS なので、カサディンやリージェントから借りるのは「仕組みの考え方」と「雰囲気」だけにする。

| 借りる（一般的な仕組み・雰囲気） | 使わない |
| --- | --- |
| 続けて唱えるほどコストも威力も上がる（カサディンの Riftwalk） | 名前、スキル名、虚空（Void）の設定と物語 |
| 繰り越せる2つ目の資源と、戦闘中に育つ専用の技（リージェント） | 紫と黒の配色、顔を覆う仮面やフード、紫の裂け目エフェクト |
| 腕や手から伸びる魔力の刃という発想 | 既存キャラの衣装・武器の形をそのまま組み合わせること |

顔は出す（Vera と同じアニメ調）。色は青・水色・白・銀に絞り、紫は使わない。

## 仕組み：マナ

- 2つ目の資源。エネルギー（毎ターン3）とは別に、**ターンをまたいで繰り越せる**（上限 10）。
- 主な入手：マナを生むスキル（「集める」系）、毎ターン開始時に +1（開始レリック）。
- 画面上は、主人公のまわりに浮かぶ青い光の玉の数で見せる。溜まるほど玉が増えて明るくなる。

## 固有の技「蒼刃（あおば）」

- 戦闘開始時に、専用カード「蒼刃」が手札に1枚入る（保留：ターン終了時に捨てられない）。
- 基本：1コスト・8ダメージ。使うと捨て札ではなく手札に戻る準備をし、次のターンにまた引ける（毎ターン1回振れる）。
- **マナを注いで強化する**：「注ぐ」系のカードで、マナを使って蒼刃に強化を1段ずつ積む。強化は戦闘の終わりまで残る。
  - 刃を伸ばす：ダメージ +6
  - 刃を分ける：敵全体に当たる
  - 刃を重ねる：攻撃回数 +1
  - 刃を研ぐ：コスト −1（0 まで）
- 画面上は、蒼刃のカード絵と主人公の魔力の刃が、強化の段階に合わせて長く・明るくなる。「剣が育って光る」が10秒で伝わる見せ場。

## 2つのビルド軸（LoL の AD / AP にあたる）

| 軸 | マナの使い道 | 勝ち筋 | 見せ場 |
| --- | --- | --- | --- |
| ヘイスト | 0コストの呪文、マナで払える呪文、ドロー。マナを「エネルギーの代わり」に使う | 1ターンに7〜8枚の呪文を撃ち、1枚ごとの効果を積む | 小さな青い弾が何発も飛ぶ |
| 蒼刃 | マナを蒼刃の強化に注ぐ | 数ターンかけて蒼刃を育て、毎ターン大きく振る | 刃が伸びて光り、敵全体をなぎ払う |

2つの軸はマナを取り合うので、ランごとにどちらへ寄せるかの判断が生まれる。少しずつ持つ混合も成り立つ（例：ヘイストで撃った枚数ぶん蒼刃が一時的に強くなるカード）。
既存の `BuildContent.gd`（タグと開始武器で軸を伸ばす仕組み）にも乗せられる：開始の二択を「早撃ちの杖（マナで払った呪文のダメージ+3）」と「蒼刃の鍔（蒼刃の強化1段目が最初から付く）」にする。

### 看板カード「蒼渡り」（カサディンの Riftwalk の考え方）

- マナ1：敵の背後へ跳んで 7 ダメージ。この戦闘で使うたびに、マナのコスト +1・ダメージ2倍。
- ヘイストと蒼刃のどちらの軸にも入る混合カード。仕組み全体にはせず、カード1枚に閉じ込める（KISS）。

## 作り方の順番

1. **デザイン候補を1枚で出す**（Codex 1回）。同じ「中性的なマッシュの少年魔法使い」で、武器とシルエットの違う4案を横に並べ、ユーザーに1案を選んでもらう。
2. 選んだ案から正本（`tools/codex_art/refs/hero_blue_master.png`）を作る（Codex 1回）。
3. 正本を参照に、アニメーション（idle / attack / hurt / block）、アイコン、バストを作る。Vera と同じく1シート1回。
4. カード絵は2〜4枚を1枚にまとめて描いて分割する（呼び出しを節約）。
5. コード：`add_characters()` に `character_blue` を足し、マナ・蒼刃・カードは `scripts/content/` に別ファイルで切り出す（`GlobalProdDataGenerator.gd` はすでに3500行を超えているため）。

注意：同じフォルダで「基本アタックを育てるビルド軸」の作業が進んでいる（同じ `BuildContent.gd` と生成スクリプトに触る）。コードの実装は、その作業が取り込まれてから別の作業場所（worktree）で行う。
